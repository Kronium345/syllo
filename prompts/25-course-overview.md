# 25 · Tutor course overview + separate Edit page

Status: done

## Goal
Tapping a course on the tutor dashboard opens a read-only **overview** of it, with an **"Edit course"** button that opens the editor on its own page.

## Decisions
- **Routes:** `/tutor/course/[id]` becomes the overview (`src/screens/tutor/course-overview-screen.tsx`); the current editor moves unchanged to the new route **`/tutor/course/[id]/edit`** (`src/app/(app)/tutor/course/[id]/edit.tsx` renders the existing `EditCourseScreen`; registered in `tutor/_layout.tsx`). The lesson editor stays at `/tutor/course/[id]/lesson/[lessonId]`.
- **Edit page (user decision): everything the editor has today** (cover, details, outline management, publishing, delete). Nothing about it changes except its address and that Back returns to the overview.
- **Overview contents (user decision):**
  - Cover (via `useCourseCover`, 16:9, `bg-track` placeholder), title, subtitle, Published/Draft badge, "Free/Premium · level · category", description.
  - **"Edit course"** (primary button, Pencil icon) → `/tutor/course/[id]/edit`.
  - **Numbers:** four tiles: chapters, lessons, quizzes, learners. Learners = `useStudentCount(id)` (the existing `course_student_count`, published courses only); a draft shows "—".
  - **Publishing card:** the same status text and Publish / Unpublish (needs a lesson; Unpublish asks first) as the editor. It's moved into a shared `PublishingCard` component (`src/screens/tutor/publishing-card.tsx`) that both pages use.
  - **Read-only outline:** each chapter ("Chapter 01", title, its lessons with position, title, "Preview" and duration, and its quiz count); tapping a lesson opens the lesson editor. Empty: "No chapters yet. Tap Edit course to add one."
  - States: loading, error + "Try again", "This course isn't available." (same as the editor).
- **After creating a course** (New course): still go straight to the **edit** page (`router.replace` to `/tutor/course/[id]/edit`), since a new draft needs chapters first; Back from there goes to the dashboard.
- **After deleting a course** (edit page): back to the dashboard, as today.
- **Data:** no new queries or schema: `useTutorCourse(id)` (outline, counts) and `useStudentCount(id)`.
- No design: built from the tokens like the other tutor screens; estimated values in the Result.

## Out of scope
Learner lists, ratings/reviews on the overview, analytics, editing anything on the overview other than Publish/Unpublish.

## Steps
1. Route: add `course/[id]/edit.tsx` (renders `EditCourseScreen`), register it; point `course/[id]/index.tsx` at the new overview; New course's redirect → `/edit`.
2. Extract `PublishingCard` from `edit-course-screen.tsx` (no visible change there).
3. Build `course-overview-screen.tsx` (+ small `stat-tile` / read-only outline pieces in `src/screens/tutor/`).

## Verification
- `tsc`, `expo lint`.
- Phone: dashboard → a course → overview (cover, badge, numbers, outline, publishing); Edit course → editor; Back → overview; tap a lesson in the overview → lesson editor; New course → lands on the edit page; Publish/Unpublish from the overview updates the badge; a draft shows "—" learners.

## AGENTS.md updates
- Route groups: `tutor/course/[id]` = overview, `tutor/course/[id]/edit` = the course editor; `PublishingCard` shared.

## Result
- **Routes:** `src/app/(app)/tutor/course/[id]/index.tsx` now renders `CourseOverviewScreen`; new `course/[id]/edit.tsx` renders the unchanged `EditCourseScreen` (registered in `tutor/_layout.tsx`). New course now lands on `/edit`. The editor's Back falls back to the overview (deep links); deleting a course uses `router.dismissTo("/tutor")` so the deleted course's overview isn't left underneath.
- **`publishing-card.tsx`:** the Publishing card (status text, Publish needs a lesson, Unpublish with its own `ConfirmSheet`) moved out of the editor and is shared; the editor lost its publish code and the "unpublish" confirm case.
- **`course-overview-screen.tsx`:** header "Course" + Published/Draft badge; 16:9 cover (`useCourseCover`); title, subtitle, "Free/Premium · level · category", description; "Edit course"; a 2×2 grid of number tiles (Chapters, Lessons, Quizzes, Learners: `useStudentCount` for published courses, "—" for drafts labelled "Learners (once published)"); Publishing card; read-only outline (chapter badge, title, quiz count, lessons with "mm:ss · Preview" or "No video", tap → lesson editor). Loading, error + "Try again", not-available states.
- **Typed routes:** the new `/edit` route only type-checked after Metro was (re)started, since route types are regenerated by the dev server.
- **Checks:** `tsc` and `expo lint` pass. **Not checked on the phone** (it wasn't connected).
- **Estimated values (no design):** stat tiles `p-4 rounded-2xl`, icon `lg` primary, value `text-20 bold`; tiles in a 2×2 grid (four in a row was too narrow); outline lesson rows `py-3`.
